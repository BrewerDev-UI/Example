# Daily Index

A two-minute daily learning app styled like a retro 8-bit game. Pick a world (topic), flip 3 cards, then beat a 3-question quiz. Each right answer earns a coin, and finishing a stage each day keeps your streak going.

## Browser version

`web/index.html` is the browser version. It's live as a claude.ai artifact: https://claude.ai/artifact/Ge2c8vTPtgk3BfFRRGbwi6

- On claude.ai, Claude writes a fresh lesson for each world every day, and your streak and coins are saved to your account.
- Opened anywhere else, it uses the built-in lessons (one per world) and saves progress in the browser.
- Sound effects can be turned on or off with the SOUND button.
